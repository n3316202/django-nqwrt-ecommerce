중첩 구조(Nested Serialization)

1. 중첩 구조 만들기

🧩 예시: Product 안에 Category를 중첩으로 표현하기
📌 모델 구조 예시
# models.py
class Category(models.Model):
    name = models.CharField(max_length=100)

    def __str__(self):
        return self.name


class Product(models.Model):
    name = models.CharField(max_length=100)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    category = models.ForeignKey(Category, on_delete=models.CASCADE)
✅ 1. CategorySerializer 만들기

# serializers.py
from rest_framework import serializers
from .models import Product, Category

class CategorySerializer(serializers.ModelSerializer):
    class Meta:
        model = Category
        fields = ["id", "name"]

✅ 2. ProductSerializer에서 Category를 중첩시키기

class ProductSerializer(serializers.ModelSerializer):
    category = CategorySerializer(read_only=True)  # 중첩으로 출력

    class Meta:
        model = Product
        fields = ["id", "name", "price", "category"]
✅ 결과 예시
{
  "id": 1,
  "name": "TV",
  "price": "999.99",
  "category": {
    "id": 1,
    "name": "Electronics"
  }
}
✅ 3. 쓰기(write)까지 하고 싶다면?
category_id를 따로 받고, category는 읽기 전용으로 분리하면 됩니다.

class ProductSerializer(serializers.ModelSerializer):
    category = CategorySerializer(read_only=True)
    category_id = serializers.PrimaryKeyRelatedField(
        queryset=Category.objects.all(), write_only=True
    )

    class Meta:
        model = Product
        fields = ["id", "name", "price", "category", "category_id"]
✅ 쓰기 요청 예시 (POST 요청 본문)

{
  "name": "Laptop",
  "price": 800,
  "category_id": 1
}
📝 정리

목적	방법
중첩 구조 출력	ForeignKey 필드를 중첩 시리얼라이저로 지정
중첩 구조 입력	PrimaryKeyRelatedField(write_only=True) 같이 별도로 지정
읽기 + 쓰기	read_only vs write_only 조합으로 처리
